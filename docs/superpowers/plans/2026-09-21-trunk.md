# Trunk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the ingest-to-episode pipeline that turns a customer's production agent traffic into immutable, replayable episodes — the shared foundation all three product layers read from.

**Architecture:** A stateless OTLP/HTTP receiver appends normalized spans to S3 as immutable newline-delimited JSON, partitioned by tenant and hour. A separate batch materializer groups those spans into hash-addressed episodes, stamps each with a replay tier, and writes a queryable index row to Postgres. Ingest never decides what an episode is, so assembly rules stay reversible and late-arriving spans are never a crisis.

**Tech Stack:** Python 3.11+, uv, FastAPI, psycopg 3 (async pool), Postgres via Supabase/Supavisor, alembic, boto3 + S3, pydantic v2, pytest, ruff.

**Spec:** `Plans/TRUNK_SPEC.md` (decisions and rationale), which is itself a companion to `Plans/PLAN.md` §4 Stage 1 (build order and gates).

## Global Constraints

Copied from `TRUNK_SPEC.md` §3. Every task's requirements implicitly include this section.

- **Python 3.11+.** `requires-python = ">=3.11"`.
- **uv** manages the virtualenv and lockfile. All commands run via `uv run`.
- **ruff** for lint and format. Select `["E", "W", "F", "I", "UP", "B", "SIM", "C4"]`, ignore `["SIM117", "SIM105"]`, `line-length = 100`, `target-version = "py311"`, `extend-exclude = ["db/alembic/versions"]`.
- **Supavisor rule — non-negotiable.** The DB is Supabase behind the Supavisor transaction pooler, which has **no server-side prepared statements**. Every DB entrypoint (the pool in `db.py`, the migration engine in `db/alembic/env.py`) MUST pass `prepare_threshold=None`, or pooled connection reuse fails at runtime with "prepared statement already exists".
- **SQL is always parameterized.** `%s` plus a params tuple. **Never** f-string a value into SQL.
- **DB access idiom** — nested `async with`, connection then cursor, exactly this shape (the nesting is deliberate and is why `SIM117` is disabled):
  ```python
  async with get_pool().connection() as conn:
      async with conn.cursor(row_factory=dict_row) as cur:
          await cur.execute("SELECT ... WHERE id = %s", (some_id,))
          row = await cur.fetchone()
  ```
- **Config through** `settings.py` **only.** `pydantic-settings` reading `.env.local`. No scattered `os.getenv`. Missing credentials raise a clear `RuntimeError` at use time, never an import crash.
- **Docstrings are one line, max.** Comments only where something non-obvious is happening — a constraint the code cannot show. Never narrate self-explanatory code.
- **Unit tests are deterministic logic only** — no DB, no network, no S3. I/O boundaries get smoke tests run by hand against real infrastructure.
- **Module shape:** `pipeline.py` (orchestrator) · `store.py` (async raw SQL) · `models.py` (pydantic) · `routes.py` (thin HTTP).
- **Assembly rules are configured values, never literals.** `TRUNK_SPEC.md` §2.3's central argument is that the first guess at these will be wrong.

**Boundaries.** `otel/` knows what OpenTelemetry is; nothing else does. `episodes/` knows what an episode is; `otel/` does not. `interfaces/` originally held two inert seams; by Task 18 it holds two real, deterministic defaults (`filter.py` since Task 15, `segment.py` since Task 18) and one seam still genuinely deferred downstream (`compare.py`, to L1/L2/L3 — TRUNK_SPEC.md §9.4, the one judgment the trunk cannot make structurally). The pure-logic modules (`hashing`, `normalize`, `validate`, `assemble`, `tier`, `filter`, `segment`, `build`) have no I/O and carry the strict-TDD tasks, because that is where silent correctness bugs live. `replay/` depends only on `episodes/` and `otel/models.py` — its one real I/O boundary is `client.py`'s `OpenAIModelClient`, injected everywhere else via the `ModelClient` protocol so `run.py` and `batch.py` stay unit-testable. `importers/` reuses `otel/models.py`'s `CanonicalSpan` and `otel/validate.py` / `otel/redact.py` / `otel/store.py` directly rather than duplicating them — per `TRUNK_SPEC.md` §2.7, an imported batch is not a parallel pipeline. `sdk/` is a separate installable package (its own `pyproject.toml`) because it ships to customer codebases, not to the trunk's own deployment.

Tasks 1–2 are foundation. 3–7 are the ingest path. 8–11 are the episode path. 12 is the gate. Each ends with a committed, independently testable deliverable.

**Tasks 13–14 are conditional, not blockers.** Per `TRUNK_SPEC.md` §2.6–§2.7, neither is required for the Stage 1 gate itself. Task 13 (batch importer) is worth doing as soon as a design partner has an existing export to backfill from; Task 14 (SDK) is specified to be built once real OTLP traffic shows what `missing_fields` actually looks like (§2.2) — do Task 12's spot-check against real traffic first, then decide whether Task 14 is next.

**Tasks 15–18 are not conditional — they complete Stage 1.** Per `TRUNK_SPEC.md` §1.1's 2026-09-21 revision, the weak-tier filter, replay harness, and flow segmentation were all named in `PLAN.md` §4 Stage 1; they were simply deferred (or, for the replay harness, just never built) by an earlier draft of this spec and are now back in scope. Once Task 18 lands, Stage 1 — trunk, weak-tier filter, replay harness, flow segmentation — is complete as `PLAN.md` §4 originally scoped it, and everything remaining is L1, L2, or L3. They can be built any time after Task 12 (15 and 18 need only Tasks 4, 8, 9; 16 needs only Tasks 4, 8; 17 needs Task 10's store and Task 16) — ordered last here because they are easiest to validate against a spot-checked, real population of episodes. 15 and 18 in particular are each other's context: run Task 18 before Task 12's re-run gate check (Task 18 Step 6) so the spot-check's flow stratification is meaningful at the same time its filter-verdict stratification becomes meaningful (Task 15 Step 7).

```python
"""Shared async Postgres connection pool, opened on FastAPI startup (main.lifespan)."""

from __future__ import annotations

from psycopg_pool import AsyncConnectionPool

from .settings import settings

_pool: AsyncConnectionPool | None = None


def get_pool() -> AsyncConnectionPool:
    global _pool
    if _pool is None:
        # open=False: importing never requires a live DB; opened at app startup.
        # prepare_threshold=None: the Supavisor transaction pooler doesn't support
        # server-side prepared statements — reused connections fail without it.
        _pool = AsyncConnectionPool(
            conninfo=settings.database_url,
            open=False,
            min_size=1,
            max_size=10,
            kwargs={"prepare_threshold": None},
        )
    return _pool


async def open_pool() -> None:
    await get_pool().open()


async def close_pool() -> None:
    global _pool
    if _pool is not None:
        await _pool.close()
        _pool = None
```

```python
"""Shared base for typed DB-row models returned to the API."""

from __future__ import annotations

from typing import Any

from pydantic import BaseModel, ConfigDict


class RowModel(BaseModel):
    """Base for a DB-query result row. Subclass with the columns you SELECT."""

    # An extra selected column shouldn't 500; declared columns stay validated.
    model_config = ConfigDict(extra="ignore")

    def as_json(self) -> dict[str, Any]:
        """JSON-safe dict: UUID -> str, datetime -> ISO 8601, etc."""
        return self.model_dump(mode="json")

    @classmethod
    def rows_to_json(cls, rows: list[dict]) -> list[dict]:
        """Validate + JSON-serialize a list of psycopg dict_row results."""
        return [cls(**row).as_json() for row in rows]

    @classmethod
    def row_to_json(cls, row: dict) -> dict:
        """Validate + JSON-serialize a single psycopg dict_row result."""
        return cls(**row).as_json()
```

```python
"""Alembic migration environment. Raw SQL migrations — no ORM models."""

from __future__ import annotations

from alembic import context
from sqlalchemy import create_engine

from continual.settings import settings


# SQLAlchemy picks psycopg2 for a bare postgresql:// URL; we install psycopg 3
# only, so the dialect has to be named explicitly.
URL = settings.database_url.replace("postgresql://", "postgresql+psycopg://", 1)


def run_migrations_online() -> None:
    # prepare_threshold=None: same Supavisor constraint as db.py. Without it,
    # migrations fail on a reused pooled connection.
    engine = create_engine(URL, connect_args={"prepare_threshold": None})
    with engine.connect() as connection:
        context.configure(connection=connection, target_metadata=None)
        with context.begin_transaction():
            context.run_migrations()


if context.is_offline_mode():
    context.configure(url=URL, target_metadata=None)
    with context.begin_transaction():
        context.run_migrations()
else:
    run_migrations_online()
```

```python
"""Deterministic content hashing — the basis of episode identity."""

from __future__ import annotations

import hashlib
import json
from typing import Any


def canonical_json(obj: Any) -> bytes:
    """Deterministic JSON bytes: sorted keys, no whitespace, UTF-8."""
    # sort_keys makes dict ordering irrelevant; lists stay ordered because span
    # order within an episode is meaningful. separators drops incidental
    # whitespace. ensure_ascii=False + explicit UTF-8 keeps non-ASCII stable
    # across platforms.
    return json.dumps(
        obj,
        sort_keys=True,
        separators=(",", ":"),
        ensure_ascii=False,
        default=str,
    ).encode("utf-8")


def content_hash(obj: Any) -> str:
    """SHA-256 of the canonical serialization, as lowercase hex."""
    return hashlib.sha256(canonical_json(obj)).hexdigest()
```

```python
"""The canonical span — our normalized form of an OTLP span."""

from __future__ import annotations

from typing import Any

from pydantic import BaseModel, Field

from ..hashing import content_hash

# Precedence for resolving which conversation a span belongs to
# (TRUNK_SPEC.md §5.2). Explicit beats conventional beats inferred.
_SESSION_ATTRIBUTE_PRECEDENCE = (
    "continual.session_id",
    "session.id",
    "gen_ai.conversation.id",
)

# Any of these marks a span as an LLM call for replay-tier purposes.
_LLM_MARKER_PREFIXES = ("gen_ai.",)


class CanonicalSpan(BaseModel):
    """One OTLP span, normalized. The unit ingest stores."""

    trace_id: str
    span_id: str
    parent_span_id: str | None = None
    name: str
    start_time_unix_nano: int
    end_time_unix_nano: int
    attributes: dict[str, Any] = Field(default_factory=dict)
    resource_attributes: dict[str, Any] = Field(default_factory=dict)
    status_code: str | None = None
    events: list[dict[str, Any]] = Field(default_factory=list)

    def span_hash(self) -> str:
        """Content hash of this span — what an episode binds to."""
        return content_hash(self.model_dump(mode="json"))

    def session_key(self) -> str:
        """Which conversation this span belongs to; falls back to the trace id."""
        for key in _SESSION_ATTRIBUTE_PRECEDENCE:
            value = self.attributes.get(key) or self.resource_attributes.get(key)
            if value:
                return str(value)
        # No session marker anywhere: degrade to one episode per trace rather
        # than dropping the span. Coarse, but never silently merges conversations.
        return self.trace_id

    def is_llm_call(self) -> bool:
        """True if this span represents a model invocation."""
        return any(
            key.startswith(prefix)
            for key in self.attributes
            for prefix in _LLM_MARKER_PREFIXES
        )
```

```python
"""OTLP/JSON payloads -> CanonicalSpan. The wire format stops here."""

from __future__ import annotations

import logging
from typing import Any

from .models import CanonicalSpan

logger = logging.getLogger("continual.otel.normalize")

_STATUS_CODES = {0: "UNSET", 1: "OK", 2: "ERROR"}


def _attr_value(value: dict[str, Any]) -> Any:
    """Unwrap one OTLP AnyValue into a plain Python value."""
    if "stringValue" in value:
        return value["stringValue"]
    if "intValue" in value:
        # OTLP/JSON encodes 64-bit ints as strings to survive JavaScript.
        return int(value["intValue"])
    if "boolValue" in value:
        return value["boolValue"]
    if "doubleValue" in value:
        return value["doubleValue"]
    if "arrayValue" in value:
        return [_attr_value(v) for v in value["arrayValue"].get("values", [])]
    if "kvlistValue" in value:
        return _flatten_attributes(value["kvlistValue"].get("values", []))
    return None


def _flatten_attributes(attributes: list[dict[str, Any]]) -> dict[str, Any]:
    """OTLP KeyValue list -> plain dict."""
    return {a["key"]: _attr_value(a.get("value", {})) for a in attributes if "key" in a}


def normalize_otlp_json(payload: dict[str, Any]) -> list[CanonicalSpan]:
    """Flatten an OTLP/JSON ExportTraceServiceRequest into canonical spans."""
    spans: list[CanonicalSpan] = []
    for resource_span in payload.get("resourceSpans", []):
        resource_attributes = _flatten_attributes(
            resource_span.get("resource", {}).get("attributes", [])
        )
        for scope_span in resource_span.get("scopeSpans", []):
            for raw in scope_span.get("spans", []):
                span = _one_span(raw, resource_attributes)
                if span is not None:
                    spans.append(span)
    return spans


def _one_span(raw: dict[str, Any], resource_attributes: dict[str, Any]) -> CanonicalSpan | None:
    """One OTLP span -> CanonicalSpan, or None if it is unusable."""
    # A span with no id cannot be addressed or deduplicated. Drop it alone —
    # rejecting the whole batch would cost every good span in the export.
    if not raw.get("spanId") or not raw.get("traceId"):
        logger.warning("dropping span with no trace/span id: name=%s", raw.get("name"))
        return None
    try:
        return CanonicalSpan(
            trace_id=raw["traceId"],
            span_id=raw["spanId"],
            parent_span_id=raw.get("parentSpanId") or None,
            name=raw.get("name", ""),
            start_time_unix_nano=int(raw.get("startTimeUnixNano", 0)),
            end_time_unix_nano=int(raw.get("endTimeUnixNano", 0)),
            attributes=_flatten_attributes(raw.get("attributes", [])),
            resource_attributes=resource_attributes,
            status_code=_STATUS_CODES.get(raw.get("status", {}).get("code", 0)),
            events=raw.get("events", []),
        )
    except (ValueError, TypeError, KeyError):
        logger.exception("dropping unparseable span: name=%s", raw.get("name"))
        return None
```

```python
"""Structural validation at the door — what makes a span storable at all."""

from __future__ import annotations

from .models import CanonicalSpan


def validate_span(span: CanonicalSpan) -> list[str]:
    """Structural problems with a span; empty list means it is storable."""
    problems: list[str] = []
    if not span.trace_id:
        problems.append("empty trace_id")
    if not span.span_id:
        problems.append("empty span_id")
    if span.start_time_unix_nano <= 0:
        problems.append("missing or zero start_time_unix_nano")
    if span.end_time_unix_nano < span.start_time_unix_nano:
        problems.append("end_time_unix_nano precedes start_time_unix_nano")
    return problems


def partition_valid(
    spans: list[CanonicalSpan],
) -> tuple[list[CanonicalSpan], list[tuple[CanonicalSpan, list[str]]]]:
    """Split spans into storable and rejected-with-reasons."""
    valid: list[CanonicalSpan] = []
    rejected: list[tuple[CanonicalSpan, list[str]]] = []
    for span in spans:
        problems = validate_span(span)
        if problems:
            rejected.append((span, problems))
        else:
            valid.append(span)
    return valid, rejected
```

```python
"""Raw span storage — S3 is the system of record (TRUNK_SPEC.md §2.4)."""

from __future__ import annotations

import gzip
import json
import logging
import uuid
from collections.abc import Iterator
from datetime import UTC, datetime, timedelta
from functools import cache

import boto3

from ..hashing import canonical_json
from ..settings import settings
from .models import CanonicalSpan

logger = logging.getLogger("continual.otel.store")

_ONE_HOUR = timedelta(hours=1)


@cache
def _client():  # noqa: ANN202 (boto3 clients are untyped)
    if not settings.s3_bucket:
        raise RuntimeError("S3_BUCKET is not set (put it in .env.local)")
    return boto3.client("s3")


def raw_key(tenant_id: str, received_at: datetime, batch_id: str) -> str:
    """S3 key for one received batch, partitioned for cheap range reads."""
    at = received_at.astimezone(UTC)
    return (
        f"raw/tenant={tenant_id}"
        f"/date={at:%Y-%m-%d}"
        f"/hour={at:%H}"
        f"/{batch_id}.jsonl.gz"
    )


def write_raw_spans(
    tenant_id: str,
    spans: list[CanonicalSpan],
    received_at: datetime | None = None,
) -> str:
    """Append one immutable batch of spans to S3; returns the key written."""
    at = received_at or datetime.now(UTC)
    # A fresh uuid per batch, never a content hash: two identical batches are two
    # real deliveries, and collapsing them would silently drop a retry we may
    # need in order to audit what the customer actually sent.
    key = raw_key(tenant_id, at, uuid.uuid4().hex)
    lines = b"\n".join(canonical_json(s.model_dump(mode="json")) for s in spans)
    _client().put_object(
        Bucket=settings.s3_bucket,
        Key=key,
        Body=gzip.compress(lines),
        ContentType="application/x-ndjson",
        ContentEncoding="gzip",
    )
    logger.info("wrote %d spans to s3://%s/%s", len(spans), settings.s3_bucket, key)
    return key


def _partition_prefixes(tenant_id: str, since: datetime, until: datetime) -> Iterator[str]:
    """Hour-partition prefixes covering [since, until]."""
    cursor = since.astimezone(UTC).replace(minute=0, second=0, microsecond=0)
    end = until.astimezone(UTC)
    while cursor <= end:
        yield f"raw/tenant={tenant_id}/date={cursor:%Y-%m-%d}/hour={cursor:%H}/"
        cursor = cursor + _ONE_HOUR


def read_raw_spans(tenant_id: str, since: datetime, until: datetime) -> Iterator[CanonicalSpan]:
    """Every stored span in the partition range, oldest partition first."""
    paginator = _client().get_paginator("list_objects_v2")
    for prefix in _partition_prefixes(tenant_id, since, until):
        for page in paginator.paginate(Bucket=settings.s3_bucket, Prefix=prefix):
            for obj in page.get("Contents", []):
                body = _client().get_object(Bucket=settings.s3_bucket, Key=obj["Key"])["Body"].read()
                for line in gzip.decompress(body).splitlines():
                    if line:
                        yield CanonicalSpan(**json.loads(line))
```

```python
"""OTLP/HTTP receiver — the front door (TRUNK_SPEC.md §2.1)."""

from __future__ import annotations

import gzip
import json
import logging

from fastapi import APIRouter, Header, Request
from fastapi.responses import JSONResponse

from .normalize import normalize_otlp_json
from .redact import redact_span
from .store import write_raw_spans
from .validate import partition_valid

logger = logging.getLogger("continual.otel.routes")

router = APIRouter(tags=["ingest"])


@router.post("/v1/traces")
async def receive_traces(
    request: Request,
    x_continual_tenant: str = Header(default=""),
) -> JSONResponse:
    """Accept one OTLP/JSON export, normalize it, and append it to the raw store."""
    if not x_continual_tenant:
        return JSONResponse({"error": "X-Continual-Tenant header is required"}, 400)

    body = await request.body()
    if request.headers.get("content-encoding") == "gzip":
        body = gzip.decompress(body)

    try:
        payload = json.loads(body)
    except json.JSONDecodeError:
        # Protobuf is the OTLP default; JSON needs OTEL_EXPORTER_OTLP_PROTOCOL=http/json.
        # Say so explicitly — this is the most likely first-integration failure.
        return JSONResponse(
            {"error": "expected OTLP/JSON; set OTEL_EXPORTER_OTLP_PROTOCOL=http/json"},
            415,
        )

    try:
        spans = normalize_otlp_json(payload)
        valid, rejected = partition_valid(spans)
        for span, problems in rejected:
            logger.warning("rejected span %s: %s", span.span_id, "; ".join(problems))
        if valid:
            write_raw_spans(x_continual_tenant, [redact_span(s) for s in valid])
    except Exception:
        logger.exception("failed to ingest traces for tenant %s", x_continual_tenant)
        return JSONResponse({"error": "ingest failed"}, 500)

    # OTLP expects partialSuccess rather than an error when some spans are dropped,
    # so a bad span never makes an exporter retry the whole batch forever.
    response: dict = {}
    if rejected:
        response["partialSuccess"] = {
            "rejectedSpans": len(rejected),
            "errorMessage": "spans failed structural validation; see server logs",
        }
    return JSONResponse(response, 200)
```

```python
def _normalize_id(value: str) -> str:
    """Trace/span ids as lowercase hex, whether they arrived hex or base64."""
    # OTLP/JSON sends hex; protobuf-decoded-to-dict sends base64. Both reach the
    # same normalizer, and an episode must hash identically either way.
    try:

        return value.lower()

        pass

    except (binascii.Error, ValueError):
```

```python
"""The episode — an immutable, content-addressed slice of one conversation."""

from __future__ import annotations

from enum import StrEnum

from pydantic import BaseModel, Field

from ..hashing import content_hash
from ..otel.models import CanonicalSpan


class ReplayTier(StrEnum):
    """Whether an episode carries enough to reconstruct its model input."""

    REPLAYABLE = "replayable"
    OBSERVE_ONLY = "observe_only"


class Episode(BaseModel):
    """One assembled conversation slice. Identity is its content hash."""

    tenant_id: str
    session_key: str
    spans: list[CanonicalSpan]
    started_at_unix_nano: int
    ended_at_unix_nano: int

    # Hash-binding (PLAN.md §4): every derived artifact names its inputs, so any
    # episode can be audited back to the raw bytes it was built from.
    source_span_hashes: list[str] = Field(default_factory=list)

    tier: ReplayTier = ReplayTier.OBSERVE_ONLY
    missing_fields: list[str] = Field(default_factory=list)

    # Stage 2 fills these through the interfaces/ seam; defaults are inert.
    flow: str = "unsegmented"
    keep: bool = True
    keep_reason: str = "no-filter-configured"

    def episode_hash(self) -> str:
        """Content-addressed id. Same spans always produce the same id."""
        # Only the spans and their identity are hashed — not tier, flow or keep.
        # Those are judgments layered on afterwards, and re-running a filter must
        # not mint a new episode id for unchanged traffic.
        return content_hash(
            {
                "tenant_id": self.tenant_id,
                "session_key": self.session_key,
                "source_span_hashes": self.source_span_hashes,
            }
        )
```

```python
"""Grouping, ordering and closing — read-time assembly (TRUNK_SPEC.md §2.3)."""

from __future__ import annotations

from ..otel.models import CanonicalSpan
from .models import Episode

_NANOS_PER_SECOND = 1_000_000_000


def assemble(
    tenant_id: str,
    spans: list[CanonicalSpan],
    idle_timeout_s: int,
    max_duration_s: int,
    now_unix_nano: int,
) -> tuple[list[Episode], list[CanonicalSpan]]:
    """Group spans into closable episodes; returns (closed, still-open spans)."""
    idle_nanos = idle_timeout_s * _NANOS_PER_SECOND
    max_nanos = max_duration_s * _NANOS_PER_SECOND

    closed: list[Episode] = []
    still_open: list[CanonicalSpan] = []

    for session_key, session_spans in _by_session(spans).items():
        ordered = sorted(session_spans, key=lambda s: (s.start_time_unix_nano, s.span_id))
        for group in _split_on_gaps(ordered, idle_nanos, max_nanos):
            last_end = max(s.end_time_unix_nano for s in group)
            # A session whose last span ended recently may still grow. Hashing it
            # now would mint an id that a span arriving next minute invalidates.
            if now_unix_nano - last_end < idle_nanos:
                still_open.extend(group)
                continue
            closed.append(_episode(tenant_id, session_key, group))

    closed.sort(key=lambda e: (e.started_at_unix_nano, e.session_key))
    return closed, still_open


def _by_session(spans: list[CanonicalSpan]) -> dict[str, list[CanonicalSpan]]:
    """Group spans by session, collapsing duplicate span ids."""
    grouped: dict[str, dict[str, CanonicalSpan]] = {}
    for span in spans:
        # Keyed by span_id: exporters retry, and the same span delivered twice is
        # one span. Without this an episode's hash would depend on delivery luck.
        grouped.setdefault(span.session_key(), {})[span.span_id] = span
    return {key: list(by_id.values()) for key, by_id in grouped.items()}


def _split_on_gaps(
    ordered: list[CanonicalSpan],
    idle_nanos: int,
    max_nanos: int,
) -> list[list[CanonicalSpan]]:
    """Split an ordered session into groups on idle gaps and the duration bound."""
    if not ordered:
        return []
    groups: list[list[CanonicalSpan]] = []
    current: list[CanonicalSpan] = [ordered[0]]
    for span in ordered[1:]:
        gap = span.start_time_unix_nano - max(s.end_time_unix_nano for s in current)
        elapsed = span.end_time_unix_nano - current[0].start_time_unix_nano
        # The max-duration bound stops a never-idle session (a long-running or
        # looping agent) from producing an episode that grows without limit.
        if gap >= idle_nanos or elapsed > max_nanos:
            groups.append(current)
            current = [span]
        else:
            current.append(span)
    groups.append(current)
    return groups


def _episode(tenant_id: str, session_key: str, group: list[CanonicalSpan]) -> Episode:
    return Episode(
        tenant_id=tenant_id,
        session_key=session_key,
        spans=group,
        started_at_unix_nano=min(s.start_time_unix_nano for s in group),
        ended_at_unix_nano=max(s.end_time_unix_nano for s in group),
        source_span_hashes=[s.span_hash() for s in group],
    )
```

```python
"""Replay-tier classification — the poison guard (TRUNK_SPEC.md §5.3)."""

from __future__ import annotations

from typing import Any

from ..otel.models import CanonicalSpan
from .models import Episode, ReplayTier

# Everything replay needs to reconstruct the exact model input. An episode
# missing any of these would replay against a DIFFERENT input than production
# saw — worse than not replaying, because it looks like it worked.
REPLAY_REQUIRED_ATTRIBUTES: tuple[str, ...] = (
    "gen_ai.request.model",
    "gen_ai.input.messages",
    "gen_ai.output.messages",
    "gen_ai.request.temperature",
    "gen_ai.request.top_p",
    "gen_ai.request.tool_definitions",
    "gen_ai.tool.results",
)


def classify_tier(episode: Episode, max_field_bytes: int) -> tuple[ReplayTier, list[str]]:
    """Whether this episode can be replayed, and what it is missing if not."""
    llm_spans = [s for s in episode.spans if s.is_llm_call()]
    if not llm_spans:
        # Nothing to replay is not the same as replayable. Saying otherwise would
        # let an episode with no model call pass a downstream replayable filter.
        return ReplayTier.OBSERVE_ONLY, ["no-llm-spans"]

    missing: set[str] = set()
    for span in llm_spans:
        for attribute in REPLAY_REQUIRED_ATTRIBUTES:
            if not _usable(span, attribute, max_field_bytes):
                missing.add(attribute)

    if missing:
        return ReplayTier.OBSERVE_ONLY, sorted(missing)
    return ReplayTier.REPLAYABLE, []


def _usable(span: CanonicalSpan, attribute: str, max_field_bytes: int) -> bool:
    """Is this attribute present, whole, and untruncated?"""
    if attribute not in span.attributes:
        return False
    value = span.attributes[attribute]
    # Presence, not truthiness: temperature 0.0 is a normal deterministic setting
    # and an empty tool-results list is a real, complete answer.
    if value is None:
        return False
    if isinstance(value, str) and not value:
        return False
    if span.attributes.get(f"{attribute}.truncated"):
        return False
    return _size_bytes(value) <= max_field_bytes


def _size_bytes(value: Any) -> int:
    if isinstance(value, str):
        return len(value.encode("utf-8"))
    return len(str(value).encode("utf-8"))


def apply_tier(episode: Episode, max_field_bytes: int) -> Episode:
    """A copy of the episode stamped with its tier and missing fields."""
    tier, missing = classify_tier(episode, max_field_bytes)
    return episode.model_copy(update={"tier": tier, "missing_fields": missing})
```

```python
"""Episode storage — S3 artifact plus the Postgres index (TRUNK_SPEC.md §2.4)."""

from __future__ import annotations

import gzip
import json
import logging
from datetime import UTC, datetime
from functools import cache

import boto3
from psycopg.rows import dict_row

from ..db import get_pool
from ..hashing import canonical_json
from ..rows import RowModel
from ..settings import settings
from .models import Episode

logger = logging.getLogger("continual.episodes.store")

_NANOS_PER_SECOND = 1_000_000_000


@cache
def _client():  # noqa: ANN202 (boto3 clients are untyped)
    if not settings.s3_bucket:
        raise RuntimeError("S3_BUCKET is not set (put it in .env.local)")
    return boto3.client("s3")


class EpisodeIndexRow(RowModel):
    """One row of the episodes index — never the episode's content."""

    episode_hash: str
    tenant_id: str
    session_key: str
    started_at: datetime
    ended_at: datetime
    span_count: int
    tier: str
    missing_fields: list[str]
    flow: str
    keep: bool
    keep_reason: str
    s3_key: str
    superseded_by: str | None = None


def episode_key(episode_hash: str) -> str:
    """S3 key for one episode artifact."""
    return f"episodes/{episode_hash}.json.gz"


def _to_utc(unix_nano: int) -> datetime:
    return datetime.fromtimestamp(unix_nano / _NANOS_PER_SECOND, tz=UTC)


async def write_episode(episode: Episode) -> str:
    """Persist one episode to S3 and index it; returns its hash."""
    episode_hash = episode.episode_hash()
    key = episode_key(episode_hash)

    _client().put_object(
        Bucket=settings.s3_bucket,
        Key=key,
        Body=gzip.compress(canonical_json(episode.model_dump(mode="json"))),
        ContentType="application/json",
        ContentEncoding="gzip",
    )

    async with get_pool().connection() as conn:
        async with conn.cursor(row_factory=dict_row) as cur:
            # ON CONFLICT DO UPDATE on the judgment columns only: re-running the
            # materializer over unchanged spans must be a no-op on identity, but
            # re-running a NEW filter over them should update the verdict.
            await cur.execute(
                """
                INSERT INTO episodes (
                    episode_hash, tenant_id, session_key, started_at, ended_at,
                    span_count, tier, missing_fields, flow, keep, keep_reason, s3_key
                ) VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s)
                ON CONFLICT (episode_hash) DO UPDATE SET
                    tier = EXCLUDED.tier,
                    missing_fields = EXCLUDED.missing_fields,
                    flow = EXCLUDED.flow,
                    keep = EXCLUDED.keep,
                    keep_reason = EXCLUDED.keep_reason
                """,
                (
                    episode_hash,
                    episode.tenant_id,
                    episode.session_key,
                    _to_utc(episode.started_at_unix_nano),
                    _to_utc(episode.ended_at_unix_nano),
                    len(episode.spans),
                    str(episode.tier),
                    json.dumps(episode.missing_fields),
                    episode.flow,
                    episode.keep,
                    episode.keep_reason,
                    key,
                ),
            )
    logger.info("indexed episode %s (%d spans)", episode_hash[:12], len(episode.spans))
    return episode_hash


async def supersede_earlier_episodes(episode: Episode, episode_hash: str) -> None:
    """Mark overlapping earlier episodes for this session as superseded."""
    # A late span produces a new hash for the same conversation slice
    # (TRUNK_SPEC.md §5.2). The old artifact is retained for audit; the pointer
    # is what tells readers which one is current.
    async with get_pool().connection() as conn:
        async with conn.cursor(row_factory=dict_row) as cur:
            await cur.execute(
                """
                UPDATE episodes
                   SET superseded_by = %s
                 WHERE tenant_id = %s
                   AND session_key = %s
                   AND episode_hash <> %s
                   AND superseded_by IS NULL
                   AND started_at <= %s
                   AND ended_at >= %s
                """,
                (
                    episode_hash,
                    episode.tenant_id,
                    episode.session_key,
                    episode_hash,
                    _to_utc(episode.ended_at_unix_nano),
                    _to_utc(episode.started_at_unix_nano),
                ),
            )


async def list_episodes(
    tenant_id: str,
    limit: int = 100,
    tier: str | None = None,
    flow: str | None = None,
) -> list[dict]:
    """Current (non-superseded) episodes for a tenant, newest first."""
    clauses = ["tenant_id = %s", "superseded_by IS NULL"]
    params: list = [tenant_id]
    if tier:
        clauses.append("tier = %s")
        params.append(tier)
    if flow:
        clauses.append("flow = %s")
        params.append(flow)
    params.append(limit)

    async with get_pool().connection() as conn:
        async with conn.cursor(row_factory=dict_row) as cur:
            await cur.execute(
                f"SELECT * FROM episodes WHERE {' AND '.join(clauses)} "
                "ORDER BY started_at DESC LIMIT %s",
                tuple(params),
            )
            rows = await cur.fetchall()
    return EpisodeIndexRow.rows_to_json(rows)


async def read_episode(episode_hash: str) -> Episode | None:
    """Fetch one episode's full content from S3."""
    try:
        body = _client().get_object(
            Bucket=settings.s3_bucket, Key=episode_key(episode_hash)
        )["Body"].read()
    except _client().exceptions.NoSuchKey:
        return None
    return Episode(**json.loads(gzip.decompress(body)))


async def latest_span_end(tenant_id: str) -> datetime | None:
    """The end of the newest materialized episode — the materializer watermark."""
    async with get_pool().connection() as conn:
        async with conn.cursor(row_factory=dict_row) as cur:
            await cur.execute(
                "SELECT max(ended_at) AS watermark FROM episodes WHERE tenant_id = %s",
                (tenant_id,),
            )
            row = await cur.fetchone()
    return row["watermark"] if row else None
```

```python
"""The materializer — raw spans become episodes (TRUNK_SPEC.md §2.3)."""

from __future__ import annotations

import logging
from datetime import UTC, datetime, timedelta

from pydantic import BaseModel

from ..interfaces.filter import classify
from ..interfaces.segment import segment
from ..otel.store import read_raw_spans
from ..settings import settings
from .assemble import assemble
from .models import Episode, ReplayTier
from .store import latest_span_end, supersede_earlier_episodes, write_episode
from .tier import apply_tier

logger = logging.getLogger("continual.episodes.materialize")

_NANOS_PER_SECOND = 1_000_000_000


class MaterializeResult(BaseModel):
    """What one materialization run did."""

    tenant_id: str
    spans_read: int
    episodes_written: int
    still_open: int
    replayable: int


async def materialize_tenant(
    tenant_id: str,
    since: datetime | None = None,
    until: datetime | None = None,
) -> MaterializeResult:
    """Assemble every closable episode for a tenant in the given window."""
    until = until or datetime.now(UTC)
    if since is None:
        watermark = await latest_span_end(tenant_id)
        # Re-read one idle window before the watermark: a span that arrived late
        # may belong to an episode we already closed, and re-materializing it is
        # exactly how a superseding episode gets produced.
        overlap = timedelta(seconds=settings.episode_idle_timeout_s)
        since = (watermark - overlap) if watermark else (until - timedelta(days=7))

    spans = list(read_raw_spans(tenant_id, since, until))
    closed, still_open = assemble(
        tenant_id=tenant_id,
        spans=spans,
        idle_timeout_s=settings.episode_idle_timeout_s,
        max_duration_s=settings.episode_max_duration_s,
        now_unix_nano=int(until.timestamp() * _NANOS_PER_SECOND),
    )

    written = 0
    replayable = 0
    for episode in closed:
        enriched = _enrich(episode)
        episode_hash = await write_episode(enriched)
        await supersede_earlier_episodes(enriched, episode_hash)
        written += 1
        if enriched.tier is ReplayTier.REPLAYABLE:
            replayable += 1

    result = MaterializeResult(
        tenant_id=tenant_id,
        spans_read=len(spans),
        episodes_written=written,
        still_open=len(still_open),
        replayable=replayable,
    )
    logger.info(
        "materialized tenant=%s spans=%d episodes=%d replayable=%d open=%d",
        tenant_id, result.spans_read, written, replayable, result.still_open,
    )
    return result


def _enrich(episode: Episode) -> Episode:
    """Stamp tier, then run the Stage 2 seams over the episode."""
    tiered = apply_tier(episode, settings.max_captured_field_bytes)
    verdict = classify(tiered)
    return tiered.model_copy(
        update={
```

```python
"""The Stage 1 gate — sample episodes for a hand spot-check (TRUNK_SPEC.md §6)."""

from __future__ import annotations

import argparse
import asyncio
import json
import logging
import random
from collections import defaultdict
from typing import Any

from ..db import close_pool, open_pool
from ..episodes.models import Episode
from ..episodes.store import list_episodes, read_episode

logging.basicConfig(level=logging.WARNING)

# What a human needs to see to judge an episode, in reading order.
_RENDERED_ATTRIBUTES = (
    "gen_ai.request.model",
    "gen_ai.input.messages",
    "gen_ai.output.messages",
    "gen_ai.tool.results",
)


def stratified_sample(rows: list[dict], n: int, seed: int) -> list[dict]:
    """Sample n episodes spread across (tier, flow, keep) strata."""
    if not rows:
        return []
    rng = random.Random(seed)

    strata: dict[tuple, list[dict]] = defaultdict(list)
    for row in rows:
        strata[(row.get("tier"), row.get("flow"), row.get("keep"))].append(row)

    # One from each stratum FIRST, then fill proportionally. A purely
    # proportional sample would miss a stratum holding 2 of 100 episodes — and a
    # rare failure family is exactly what the gate needs to catch.
    sample: list[dict] = []
    for key in sorted(strata, key=str):
        sample.append(rng.choice(strata[key]))

    if len(sample) >= n:
        return rng.sample(sample, n)

    chosen = {row["episode_hash"] for row in sample}
    remaining = [row for row in rows if row["episode_hash"] not in chosen]
    rng.shuffle(remaining)
    sample.extend(remaining[: n - len(sample)])
    return sample


def render_episode(episode: Episode) -> str:
    """One episode as readable text for a human reviewer."""
    lines = [
        f"session: {episode.session_key}",
        f"tier:    {episode.tier}  flow: {episode.flow}  keep: {episode.keep} ({episode.keep_reason})",
        f"spans:   {len(episode.spans)}",
        "",
    ]
    for i, span in enumerate(episode.spans, 1):
        lines.append(f"--- span {i}: {span.name} ---")
        for attribute in _RENDERED_ATTRIBUTES:
            value = span.attributes.get(attribute)
            if value:
                lines.append(f"  {attribute}: {_readable(value)}")
        lines.append("")
    return "\n".join(lines)


def _readable(value: Any) -> str:
    """Pretty-print a JSON-ish attribute, or fall back to str."""
    if isinstance(value, str):
        try:
            return json.dumps(json.loads(value), indent=2)[:2000]
        except json.JSONDecodeError:
            return value[:2000]
    return str(value)[:2000]


def agreement_rate(verdicts: list[tuple[bool, bool]]) -> float:
    """Fraction of (machine, human) verdict pairs that agree."""
    if not verdicts:
        # An agreement rate over nothing is not 0.0 or 1.0 — it is undefined, and
        # returning a number here would let an empty check report as a pass.
        raise ValueError("no verdicts to compare")
    return sum(1 for machine, human in verdicts if machine == human) / len(verdicts)


async def _run(tenant: str, n: int, seed: int) -> None:
    await open_pool()
    try:
        rows = await list_episodes(tenant, limit=10_000)
        if not rows:
            print(f"no episodes for tenant {tenant}")
            return
        sample = stratified_sample(rows, n, seed)
        print(f"{len(rows)} episodes; reviewing {len(sample)}\n")

        verdicts: list[tuple[bool, bool]] = []
        for i, row in enumerate(sample, 1):
            episode = await read_episode(row["episode_hash"])
            if episode is None:
                continue
            print(f"\n{'=' * 70}\n[{i}/{len(sample)}] {row['episode_hash'][:12]}\n{'=' * 70}")
            print(render_episode(episode))
            answer = input("keep this episode? [y/n/s=skip] ").strip().lower()
            if answer == "s":
                continue
            verdicts.append((bool(row["keep"]), answer == "y"))

        if verdicts:
            rate = agreement_rate(verdicts)
            print(f"\n{'=' * 70}")
            print(f"agreement: {rate:.1%} over {len(verdicts)} episodes")
            print("PLAN.md Stage 1 gate: does the keep-set survive the spot-check?")
        else:
            print("\nno verdicts recorded")
    finally:
        await close_pool()


def main() -> None:
    parser = argparse.ArgumentParser(description="Hand spot-check a sample of episodes")
    parser.add_argument("--tenant", required=True)
    parser.add_argument("--n", type=int, default=30)
    parser.add_argument("--seed", type=int, default=1, help="reproducible sampling")
    args = parser.parse_args()
    asyncio.run(_run(args.tenant, args.n, args.seed))


if __name__ == "__main__":
    main()
```

```python
Field names below follow LangSmith's documented run-export JSONL shape as of

before running this against real data.

from __future__ import annotations

import json
import logging
from collections.abc import Iterator
from datetime import datetime
from pathlib import Path
from typing import Any

from ..otel.models import CanonicalSpan

logger = logging.getLogger("continual.importers.langsmith")

_IMPORT_SOURCE = "batch:langsmith"


def _iso_to_unix_nano(ts: str) -> int:
    """LangSmith timestamps are ISO 8601; the trunk's unit is unix nanos."""
    return int(datetime.fromisoformat(ts.replace("Z", "+00:00")).timestamp() * 1_000_000_000)


def _flatten_messages(value: Any) -> list[Any]:
    """LangSmith nests messages per-generation (list[list[...]]); flatten to one list."""
    if not value:
        return []
    if isinstance(value[0], list):
        return [m for group in value for m in group]
    return value


def _one_run(raw: dict[str, Any]) -> CanonicalSpan | None:
    """One LangSmith run record -> CanonicalSpan, or None if unusable / not an LLM call."""
    # Only `llm` runs carry gen_ai.* content; chain/tool runs are structural
    # and do not affect replay-tier (TRUNK_SPEC.md §5.3 only inspects
    # LLM-call spans), so importing them would just be dead weight.
    if raw.get("run_type") != "llm":
        return None

    run_id = raw.get("id")
    if not run_id or not raw.get("start_time") or not raw.get("end_time"):
        logger.warning("dropping unusable run: id=%s", run_id)
        return None

    invocation = raw.get("extra", {}).get("invocation_params", {}) or {}
    inputs = raw.get("inputs", {}) or {}
    outputs = raw.get("outputs", {}) or {}

    attrs = {
        "gen_ai.request.model": invocation.get("model") or invocation.get("model_name"),
        "gen_ai.request.temperature": invocation.get("temperature"),
        "gen_ai.request.top_p": invocation.get("top_p"),
        "gen_ai.input.messages": json.dumps(_flatten_messages(inputs.get("messages"))),
        "gen_ai.output.messages": json.dumps(_flatten_messages(outputs.get("generations"))),
        "gen_ai.request.tools": json.dumps(invocation.get("tools", [])),
        "continual.session_id": raw.get("session_id") or raw.get("trace_id") or run_id,
        "continual.import.source": _IMPORT_SOURCE,
    }
    # Missing beats present-but-null: Tasks 5 and 9 check field presence, and a
    # null value would be silently indistinguishable from "captured as null".
    attributes = {k: v for k, v in attrs.items() if v is not None}

    try:
        return CanonicalSpan(
            trace_id=raw.get("trace_id") or run_id,
            span_id=run_id,
            parent_span_id=raw.get("parent_run_id"),
            name=raw.get("name", "langsmith-run"),
            start_time_unix_nano=_iso_to_unix_nano(raw["start_time"]),
            end_time_unix_nano=_iso_to_unix_nano(raw["end_time"]),
            attributes=attributes,
            resource_attributes={"service.name": "langsmith-import"},
        )
    except (ValueError, TypeError, KeyError):
        logger.exception("dropping unparseable run: id=%s", run_id)
        return None


def parse_langsmith_export(path: Path) -> Iterator[CanonicalSpan]:
    """One LangSmith export file (JSONL, one run per line) -> CanonicalSpan stream."""
    with path.open() as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            span = _one_run(json.loads(line))
            if span is not None:
                yield span
```

```python
"""Batch import — one-time historical backfill (TRUNK_SPEC.md §2.7).

An imported batch is not a parallel pipeline: it is pushed through the same
validate -> redact -> raw-store path a live OTLP delivery uses, so everything
downstream (materialization, tiering, the spot-check CLI) cannot tell the
difference between imported and live spans except by provenance
(`continual.import.source`).
"""

from __future__ import annotations

import logging
from pathlib import Path

from pydantic import BaseModel

from ..otel.redact import redact_span
from ..otel.store import write_raw_spans
from ..otel.validate import partition_valid
from .base import ImportAdapter
from .langsmith import parse_langsmith_export

logger = logging.getLogger("continual.importers")

ADAPTERS: dict[str, ImportAdapter] = {
    "langsmith": parse_langsmith_export,
}


class ImportResult(BaseModel):
    """What one import run did."""

    tenant_id: str
    vendor: str
    spans_read: int
    spans_written: int
    spans_rejected: int


def import_batch(tenant_id: str, vendor: str, path: Path) -> ImportResult:
    """Read one vendor export and write it through the ordinary raw-span path."""
    adapter = ADAPTERS.get(vendor)
    if adapter is None:
        raise ValueError(f"no import adapter for vendor={vendor!r}; have {sorted(ADAPTERS)}")

    spans = list(adapter(path))
    valid, rejected = partition_valid(spans)
    for span, problems in rejected:
        logger.warning("rejected imported span %s: %s", span.span_id, "; ".join(problems))
    if valid:
        write_raw_spans(tenant_id, [redact_span(s) for s in valid])

    result = ImportResult(
        tenant_id=tenant_id,
        vendor=vendor,
        spans_read=len(spans),
        spans_written=len(valid),
        spans_rejected=len(rejected),
    )
    logger.info(
        "imported vendor=%s tenant=%s read=%d written=%d rejected=%d",
        vendor, tenant_id, result.spans_read, result.spans_written, result.spans_rejected,
    )
    return result
```

```python
"""Session-ID propagation — first in the trunk's own precedence order
(TRUNK_SPEC.md §5.2), so an SDK-wrapped call's session is never inferred."""

from __future__ import annotations

import uuid
from collections.abc import Iterator
from contextlib import contextmanager
from contextvars import ContextVar

_session_id: ContextVar[str | None] = ContextVar("continual_session_id", default=None)


def current_session_id() -> str | None:
    """The session ID in effect right now, or None outside any `session()` block."""
    return _session_id.get()


@contextmanager
def session(session_id: str | None = None) -> Iterator[str]:
    """Every span emitted inside this block carries `continual.session_id`."""
    sid = session_id or uuid.uuid4().hex
    token = _session_id.set(sid)
    try:
        yield sid
    finally:
        _session_id.reset(token)
```

```python
    if _initialized:
```

```python
"""Wraps an OpenAI-shaped client so every call emits a span carrying every
field TRUNK_SPEC.md §5.3 requires for `replayable` — unconditionally, by
construction. This is the SDK's entire reason to exist (TRUNK_SPEC.md §2.6)."""

from __future__ import annotations

import json
from typing import Any

from opentelemetry.trace import Status, StatusCode

from .session import current_session_id
from .tracer import tracer


class _WrappedCompletions:
    def __init__(self, completions: Any) -> None:
        self._completions = completions

    def create(self, **kwargs: Any) -> Any:
        with tracer().start_as_current_span(f"chat {kwargs.get('model', 'unknown')}") as span:
            span.set_attribute("gen_ai.request.model", kwargs.get("model", ""))
            span.set_attribute("gen_ai.input.messages", json.dumps(kwargs.get("messages", [])))
            if "temperature" in kwargs:
                span.set_attribute("gen_ai.request.temperature", kwargs["temperature"])
            if "top_p" in kwargs:
                span.set_attribute("gen_ai.request.top_p", kwargs["top_p"])
            if "tools" in kwargs:
                span.set_attribute("gen_ai.request.tools", json.dumps(kwargs["tools"]))
            session_id = current_session_id()
            if session_id:
                span.set_attribute("continual.session_id", session_id)

            try:
                response = self._completions.create(**kwargs)
            except Exception as exc:
                span.set_status(Status(StatusCode.ERROR, str(exc)))
                raise

            messages = [
                {"role": c.message.role, "content": c.message.content} for c in response.choices
            ]
            span.set_attribute("gen_ai.output.messages", json.dumps(messages))
            return response


class _WrappedChat:
    def __init__(self, chat: Any) -> None:
        self.completions = _WrappedCompletions(chat.completions)


class _WrappedClient:
    """A transparent proxy: every attribute but `.chat` passes through untouched."""

    def __init__(self, client: Any) -> None:
        self._client = client
        self.chat = _WrappedChat(client.chat)

    def __getattr__(self, name: str) -> Any:
        return getattr(self._client, name)


def wrap(client: Any) -> _WrappedClient:
    """Return a proxy over an OpenAI-shaped client that traces every chat call."""
    return _WrappedClient(client)
```

```python
"""Weak-tier filter (TRUNK_SPEC.md §8) — structural checks only, never a
correctness judgment. This answers "is this episode usable as a training
example," not "was the agent's behavior good." See §8.3: these rules are
this spec's own derivation, not a verified port of `tau/build_sft.py`."""

from __future__ import annotations

from pydantic import BaseModel

from ..episodes.models import Episode, ReplayTier
from ..otel.models import CanonicalSpan
from ..settings import settings


class Verdict(BaseModel):
    """Whether an episode survives the weak-tier filter, and why."""

    keep: bool
    reason: str
    confidence: float | None = None


def _terminal_llm_span(spans: list[CanonicalSpan]) -> CanonicalSpan | None:
    llm_spans = [s for s in spans if s.is_llm_call()]
    if not llm_spans:
        return None
    return max(llm_spans, key=lambda s: s.end_time_unix_nano)


def _output_is_empty(span: CanonicalSpan) -> bool:
    value = span.attributes.get("gen_ai.output.messages")
    if not value:
        return True
    if isinstance(value, str):
        return value.strip() in ("", "[]", "null")
    if isinstance(value, list):
        return len(value) == 0
    return False


def classify(episode: Episode) -> Verdict:
    """Keep or drop this episode as an SFT training candidate (TRUNK_SPEC.md §8.1)."""
    if episode.tier != ReplayTier.REPLAYABLE:
        return Verdict(keep=False, reason=f"not replayable: missing {episode.missing_fields}")

    llm_spans = [s for s in episode.spans if s.is_llm_call()]
    if any(s.status_code == "ERROR" for s in llm_spans):
        return Verdict(keep=False, reason="terminal call status ERROR")

    terminal = _terminal_llm_span(episode.spans)
    if terminal is None:
        return Verdict(keep=False, reason="no LLM-call spans")
    if _output_is_empty(terminal):
        return Verdict(keep=False, reason="empty terminal output")

    if len(episode.spans) > settings.max_span_count_for_sft:
        return Verdict(
            keep=False,
            reason=f"episode too long for SFT ({len(episode.spans)} > {settings.max_span_count_for_sft})",
        )

    return Verdict(keep=True, reason="passed structural checks")
```

```python
"""Pure reconstruction of a model input from a replayable episode (TRUNK_SPEC.md §9.2)."""

from __future__ import annotations

import json
from typing import Any

from ..otel.models import CanonicalSpan
from .models import ReplayInput, ReplayOverrides


def _terminal_llm_span(spans: list[CanonicalSpan]) -> CanonicalSpan | None:
    llm_spans = [s for s in spans if s.is_llm_call()]
    if not llm_spans:
        return None
    return max(llm_spans, key=lambda s: s.end_time_unix_nano)


def _splice_system_prompt(messages: list[dict[str, Any]], new_prompt: str) -> list[dict[str, Any]]:
    spliced = list(messages)
    for i, message in enumerate(spliced):
        if message.get("role") == "system":
            spliced[i] = {**message, "content": new_prompt}
            return spliced
    return [{"role": "system", "content": new_prompt}, *spliced]


def _load(value: Any, default: Any) -> Any:
    if not value:
        return default
    return json.loads(value) if isinstance(value, str) else value


def build_replay_input(episode, overrides: ReplayOverrides | None = None) -> ReplayInput:
    """Reconstruct exactly what production sent to the model, then apply overrides."""
    overrides = overrides or ReplayOverrides()
    target = _terminal_llm_span(episode.spans)
    if target is None:
        raise ValueError(f"episode {episode.episode_hash()} has no LLM-call spans")

    messages = _load(target.attributes.get("gen_ai.input.messages"), [])
    if overrides.system_prompt is not None:
        messages = _splice_system_prompt(messages, overrides.system_prompt)

    return ReplayInput(
        model=overrides.model or target.attributes.get("gen_ai.request.model", ""),
        messages=messages,
        temperature=(
            overrides.temperature
            if overrides.temperature is not None
            else target.attributes.get("gen_ai.request.temperature")
        ),
        top_p=(
            overrides.top_p
            if overrides.top_p is not None
            else target.attributes.get("gen_ai.request.top_p")
        ),
        tools=(
            overrides.tools
            if overrides.tools is not None
            else _load(target.attributes.get("gen_ai.request.tools"), [])
        ),
    )
```

```python
"""ModelClient — the harness's only dependency on a real provider (TRUNK_SPEC.md §9.2).

An abstraction, not a wrapper of convenience: L1/L2/L3 each replay against
whatever model they are evaluating, and the harness must not be hard-wired
to one vendor."""

from __future__ import annotations

from typing import Any, Protocol

from pydantic import BaseModel


class ModelMessage(BaseModel):
    role: str
    content: str


class ModelResponse(BaseModel):
    """A ModelClient's normalized return shape, regardless of provider."""

    messages: list[ModelMessage]


class ModelClient(Protocol):
    def complete(
        self,
        model: str,
        messages: list[dict[str, Any]],
        temperature: float | None = None,
        top_p: float | None = None,
        tools: list[dict[str, Any]] | None = None,
    ) -> ModelResponse: ...


class OpenAIModelClient:
    """A real ModelClient backed by the `openai` package. The harness's one
    genuine I/O boundary — smoke-tested by hand, not unit-tested."""

    def __init__(self, client: Any = None) -> None:
        import openai

        self._client = client or openai.OpenAI()

    def complete(
        self,
        model: str,
        messages: list[dict[str, Any]],
        temperature: float | None = None,
        top_p: float | None = None,
        tools: list[dict[str, Any]] | None = None,
    ) -> ModelResponse:
        kwargs: dict[str, Any] = {"model": model, "messages": messages}
        if temperature is not None:
            kwargs["temperature"] = temperature
        if top_p is not None:
            kwargs["top_p"] = top_p
        if tools:
            kwargs["tools"] = tools
        response = self._client.chat.completions.create(**kwargs)
        return ModelResponse(
            messages=[
                ModelMessage(role=c.message.role, content=c.message.content or "")
                for c in response.choices
            ]
        )
```

```python
"""Single-episode replay (TRUNK_SPEC.md §9.1) — reconstruct, call, pair. Does
not judge the result; that is the comparator seam in `continual.interfaces.compare`."""

from __future__ import annotations

import json
import time
from typing import Any

from ..episodes.models import Episode, ReplayTier
from .build import _terminal_llm_span, build_replay_input
from .client import ModelClient
from .models import ReplayOverrides, ReplayResult


def _load(value: Any) -> list[dict[str, Any]]:
    if not value:
        return []
    return json.loads(value) if isinstance(value, str) else value


def replay_episode(
    episode: Episode,
    client: ModelClient,
    overrides: ReplayOverrides | None = None,
) -> ReplayResult:
    """Re-invoke the model for one episode's terminal call; never raises on a client error."""
    if episode.tier != ReplayTier.REPLAYABLE:
        raise ValueError(f"episode {episode.episode_hash()} is not replayable: {episode.missing_fields}")

    replay_input = build_replay_input(episode, overrides)
    terminal = _terminal_llm_span(episode.spans)
    production_output = _load(terminal.attributes.get("gen_ai.output.messages")) if terminal else []

    start = time.monotonic()
    error: str | None = None
    replay_output: list[dict[str, Any]] = []
    try:
        response = client.complete(
            model=replay_input.model,
            messages=replay_input.messages,
            temperature=replay_input.temperature,
            top_p=replay_input.top_p,
            tools=replay_input.tools,
        )
        replay_output = [{"role": m.role, "content": m.content} for m in response.messages]
    except Exception as exc:  # noqa: BLE001 — a provider failure is data, not a crash
        error = str(exc)
    latency_ms = (time.monotonic() - start) * 1000

    return ReplayResult(
        episode_hash=episode.episode_hash(),
        production_output=production_output,
        replay_output=replay_output,
        overrides_applied=(overrides or ReplayOverrides()).model_dump(exclude_none=True),
        latency_ms=latency_ms,
        error=error,
    )
```

```python
"""Comparator seam (TRUNK_SPEC.md §9.4) — L1/L2/L3 each plug in their own
notion of "better"; the trunk ships an inert, exact-match default."""

from __future__ import annotations

from pydantic import BaseModel

from ..replay.models import ReplayResult


class ComparisonVerdict(BaseModel):
    """Whether a replay's output matches production, and why."""

    same: bool
    note: str


def compare(result: ReplayResult) -> ComparisonVerdict:
    """Exact-match smoke check. Not a correctness judgment — TRUNK_SPEC.md §9.4."""
    if result.error:
        return ComparisonVerdict(same=False, note=f"replay call failed: {result.error}")
    same = result.production_output == result.replay_output
    return ComparisonVerdict(same=same, note="exact match" if same else "output differs from production")
```

```python
"""Batch replay orchestrator — the CLI's entrypoint (TRUNK_SPEC.md §9.2)."""

from __future__ import annotations

import logging

from pydantic import BaseModel

from ..episodes.store import list_episodes, read_episode
from ..interfaces.compare import compare
from .client import ModelClient
from .models import ReplayOverrides, ReplayResult
from .run import replay_episode

logger = logging.getLogger("continual.replay.batch")


class ReplayBatchResult(BaseModel):
    """What one batch replay run did."""

    tenant_id: str
    episodes_attempted: int
    episodes_succeeded: int
    episodes_errored: int
    matches_production: int
    results: list[ReplayResult]


async def replay_batch(
    tenant_id: str,
    client: ModelClient,
    overrides: ReplayOverrides | None = None,
    flow: str | None = None,
    n: int = 20,
) -> ReplayBatchResult:
    """Replay up to n kept, replayable episodes for a tenant."""
    rows = await list_episodes(tenant_id, limit=n, tier="replayable", flow=flow)
    results: list[ReplayResult] = []
    errored = 0
    matches = 0
    for row in rows:
        episode = await read_episode(row["episode_hash"])
        if episode is None or not episode.keep:
            continue
        result = replay_episode(episode, client, overrides)
        if result.error:
            errored += 1
        elif compare(result).same:
            matches += 1
        results.append(result)

    logger.info(
        "replayed tenant=%s attempted=%d errored=%d matches_production=%d",
        tenant_id, len(results), errored, matches,
    )
    return ReplayBatchResult(
        tenant_id=tenant_id,
        episodes_attempted=len(results),
        episodes_succeeded=len(results) - errored,
        episodes_errored=errored,
        matches_production=matches,
        results=results,
    )
```

```python
"""Replay run report — a batch job's output, not a live service (TRUNK_SPEC.md §9.3)."""

from __future__ import annotations

import gzip
import uuid
from datetime import UTC, datetime
from functools import cache
from pathlib import Path

import boto3

from ..settings import settings
from .batch import ReplayBatchResult


@cache
def _client():  # noqa: ANN202
    return boto3.client("s3")


def write_local_report(result: ReplayBatchResult, path: Path) -> Path:
    """One JSON line per episode result, for a human to read or diff."""
    lines = "\n".join(r.model_dump_json() for r in result.results)
    path.write_text(lines + "\n" if lines else "")
    return path


def write_s3_report(result: ReplayBatchResult, run_id: str | None = None) -> str:
    """Same content, written to S3 for a run against real infrastructure."""
    run_id = run_id or uuid.uuid4().hex
    key = f"replays/tenant={result.tenant_id}/{datetime.now(UTC):%Y-%m-%d}/{run_id}.jsonl.gz"
    lines = "\n".join(r.model_dump_json() for r in result.results).encode()
    _client().put_object(
        Bucket=settings.s3_bucket,
        Key=key,
        Body=gzip.compress(lines),
        ContentType="application/x-ndjson",
        ContentEncoding="gzip",
    )
    return key
```

```python
"""Replay N stored episodes against a candidate change, or unchanged as a
baseline determinism check (TRUNK_SPEC.md §9)."""

from __future__ import annotations

import argparse
import asyncio
import json
import logging
from pathlib import Path

from ..db import close_pool, open_pool
from ..replay.batch import replay_batch
from ..replay.client import OpenAIModelClient
from ..replay.models import ReplayOverrides
from ..replay.report import write_local_report, write_s3_report

logging.basicConfig(level=logging.INFO, format="%(levelname)-5.5s [%(name)s] %(message)s")


async def _run(tenant: str, flow: str | None, n: int, overrides_path: str | None, out: str, to_s3: bool) -> None:
    overrides = ReplayOverrides()
    if overrides_path:
        overrides = ReplayOverrides(**json.loads(Path(overrides_path).read_text()))

    await open_pool()
    try:
        result = await replay_batch(tenant, OpenAIModelClient(), overrides, flow, n)
    finally:
        await close_pool()

    print(
        f"attempted={result.episodes_attempted} "
        f"succeeded={result.episodes_succeeded} "
        f"errored={result.episodes_errored} "
        f"matches_production={result.matches_production}"
    )
    if to_s3:
        print("wrote", write_s3_report(result))
    else:
        print("wrote", write_local_report(result, Path(out)))


def main() -> None:
    parser = argparse.ArgumentParser(description="Replay stored episodes against a candidate change")
    parser.add_argument("--tenant", required=True)
    parser.add_argument("--flow")
    parser.add_argument("--n", type=int, default=20)
    parser.add_argument("--overrides", help="path to a JSON file of ReplayOverrides fields")
    parser.add_argument("--out", default="replay-report.jsonl")
    parser.add_argument("--s3", action="store_true", help="write the report to S3 instead of --out")
    args = parser.parse_args()
    asyncio.run(_run(args.tenant, args.flow, args.n, args.overrides, args.out, args.s3))


if __name__ == "__main__":
    main()
```

```python
"""Flow segmentation (TRUNK_SPEC.md §7) — a real, product-agnostic default:
episodes are bucketed by which tools were on offer, not by product-specific
semantics. `segment()`'s signature does not change when L1 later drops in a
semantic classifier (§7.3) — this section only made the *default* real."""

from __future__ import annotations

import json
from typing import Any

from ..episodes.models import Episode
from ..otel.models import CanonicalSpan


def _tool_name(tool: dict[str, Any]) -> str | None:
    function = tool.get("function")
    if isinstance(function, dict) and function.get("name"):
        return function["name"]
    return tool.get("name")


def _tools_offered(span: CanonicalSpan) -> set[str]:
    raw = span.attributes.get("gen_ai.request.tools")
    if not raw:
        return set()
    tools = json.loads(raw) if isinstance(raw, str) else raw
    return {name for tool in tools if (name := _tool_name(tool))}


def segment(episode: Episode) -> str:
    """Which flow this episode belongs to — the tool-call signature (TRUNK_SPEC.md §7.1)."""
    llm_spans = [s for s in episode.spans if s.is_llm_call()]

    tool_names: set[str] = set()
    for span in llm_spans:
        tool_names |= _tools_offered(span)

    if tool_names:
        return f"tools:{','.join(sorted(tool_names))}"

    model = llm_spans[0].attributes.get("gen_ai.request.model") if llm_spans else None
    return f"no-tools:{model or 'unknown'}"
```
